# keywords_ng.txt (除外ワードリスト)
#
# ここに書いたワードが本文に1つでも含まれる投稿は、
# いいねやRTがどれだけ伸びていても通知しない。
#
# 目的:
#   「エンゲージメントは非常に高いが、TikTok動画のネタには絶対にならない投稿」
#   を入口で落とすため。X上でいいねが爆伸びする投稿の相当数は
#   プレゼント企画・懸賞・相互フォローで、これらは伸び率だけ見ると
#   本物のニュースと区別がつかない。伸び率のロジックをいくら改善しても
#   このノイズは消えないので、ワードで落とすのが最も確実で安上がり。
#
# 【書き方】keywords.txt と同じ(1行1ワード / カンマ区切り / #はコメント)
#
# ★運用のコツ: 「なんでこれが通知されたんだ」という投稿が来たら、
#   その投稿に特有のワードをここに1行足す。それだけで次回から消える。
#
# ★★注意: ここのワードは「1つでも含まれたら問答無用で捨てる」拒否権です。
#   本物のニュースにも出てきうる一般語を入れると、拾いたい投稿まで消えます。
#   実際にあった失敗例:
#     「ご来場ありがとう」をNGに入れた
#       → 「謝罪文を公開しました。ご来場ありがとうございました」が消えた
#   入れる前に「この語が、拾いたい投稿に出てくる可能性はゼロか?」と
#   自問してください。少しでも迷うなら入れない方が安全です。
