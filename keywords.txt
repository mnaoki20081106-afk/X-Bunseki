# keywords.txt — 監視するワード
#
# ここに書いたワードは、そのままX検索クエリのOR条件になります。
#   例: (炎上 OR 文春砲 OR 熱愛報道 OR ...) lang:ja -filter:retweets min_faves:50
# GitHub上で直接編集すれば、次の実行(最大15分後)から反映されます。
#
# 【書き方】
# - 1行に1ワードでも、カンマ区切りで複数並べてもOK
# - 空行と「# 」で始まる行は無視されます
# - 2文字以上にしてください(1文字だと検索ノイズが多すぎるため)
#
# 【選び方の原則】★ここを間違えると全部無駄になります
# - ○ 半年後も使える語     … 「文春砲」「批判殺到」「活動休止」
# - × 今週だけの固有名詞   … 特定のタレント名、今話題のイベント名
#   一度きりの固有名詞を入れると、その話題が終わった瞬間に死にワードになります。
#   人名で追いたい場合は keywords_combo.txt の方が適しています。
#
# 【2026-08-23の見直しについて】
# 以前は地震・台風・津波などの災害系が中心でしたが、
#   - 全メディアが数分で報じるためスクープにならない
#   - TikTokの収益化・ガイドライン面で扱いづらい
#   - 「速報消費」が中心で、解説動画の需要が薄い
# という理由で外しました。逮捕・事件系は「芸能人の場合だけ」拾いたいので、
# keywords_combo.txt の組み合わせ検索に移しています。
