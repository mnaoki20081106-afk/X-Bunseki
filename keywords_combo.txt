# keywords_combo.txt — 組み合わせ検索
#
# 1行が、そのまま1本のX検索クエリになります。
# keywords.txt が「OR条件のワード」なのに対して、こちらは
# 「AND条件を含む、もっと細かい絞り込み」を書ける場所です。
#
# 【書き方】
#   スペース区切り = AND条件
#   (A OR B)      = どれか1つ
#   -C            = Cを含むものを除外
#   "A B"         = フレーズ完全一致
#
#   例: (逮捕 OR 起訴) (俳優 OR タレント)
#       → 「逮捕または起訴」かつ「俳優またはタレント」を含む投稿
#
# lang:ja -filter:retweets min_faves:◯◯ は自動で付くので書かないでください。
#
# 【なぜこのファイルが必要か】
# 「逮捕」「事件」「事故」のようなワードは、単独で検索すると
# 一般ニュースアカウントの速報で埋まってしまいます。全メディアが数分で
# 報じる話題なのでスクープにならず、実際にv3ではここに埋もれていました。
#
# かといってワードごと捨てると、「芸能人の逮捕」という
# TikTokの解説動画で最も需要が高いジャンルまで拾えなくなります。
#
# そこで「逮捕」に「芸能人の文脈」をAND条件で掛けることで、
# 一般ニュースを除きつつ、おいしい部分だけを残します。
#
# 【運用のコツ】
# 1行増やすたびにX検索が1回増えるので、実行時間も伸びます。
# 6〜10行くらいまでを目安にしてください。
